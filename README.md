# DevPort

Portfolio full-stack com frontend React (Vite) e backend Express.

## Scripts

- `npm install`
- `npm run dev` (API + client)
- `npm run dev:client` (apenas client)
- `npm run build`
- `npm run start`

## Estrutura

- `client/` UI React + Tailwind
- `server/` API Express
- `shared/` schemas e tipos

## Variaveis de ambiente

- `SESSION_SECRET`
- `DATABASE_URL` (opcional, sessions persistentes)
- `CORS_ORIGIN` (lista separada por virgula)
